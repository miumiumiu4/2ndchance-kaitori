# 写真の置き場

- 写真はここに `<品目>-<番号>.webp` で置く（例：`fridge-01.webp`、`sofa-03.webp`）。品目は `data/items.json` の `id`。
- `data/results.json` の `photo` で参照する（例：`"photo": "assets/items/fridge-01.webp"`）。
- 商品単体に切り抜き、背景を整えてから webp にする。幅は 800px 程度まで。
- 人の顔・名前・住所・表札・車のナンバーが写った写真は使わない（写り込みはぼかす）。
- ファイル名に人名・地名を入れない。元写真は共有フォルダに保管し、リポジトリには入れない。
